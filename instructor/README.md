# Instructor Material

Do not store answer keys, passwords, challenge flags, VPN keys, or private grading rubrics in the student-facing repository.

Recommended approach:
1. Create a separate private repository such as `CyberLabs-Instructor`.
2. Restrict access to E-board members and approved event leads.
3. Store answer keys, lab reset instructions, capstone score sheets, private challenge files, and temporary credentials there.
4. Never commit long-lived secrets.
