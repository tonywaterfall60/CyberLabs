# Beginner Extra Practice

This pathway gives newer Cyber Club members short, repeatable labs that reinforce the main Beginner track without requiring Intermediate-level independence.

## Recommended Use

Use these labs:

- after the matching Beginner event,
- during open lab nights,
- when a member wants repetition,
- before the Beginner CTF,
- before the Beginner → Intermediate readiness interview.

Each lab is designed to take roughly **20–45 minutes** and has one dashboard flag.

## Lab Path

| Lab | Topic | Main Skill |
|---|---|---|
| B01 | [Linux Navigation](B01-linux-navigation/) | files, directories, hidden files, permissions |
| B02 | [Command-Line Filtering](B02-command-line-filtering/) | grep, cut, sort, uniq, wc |
| B03 | [Networking Basics](B03-networking-basics/) | IP, DNS, ports, TCP/UDP |
| B04 | [Service Discovery](B04-service-discovery/) | Nmap, curl, manual validation |
| B05 | [HTTP and curl](B05-http-and-curl/) | requests, headers, status codes |
| B06 | [Packet Reading](B06-packet-reading/) | Wireshark/tshark basics |
| B07 | [Encoding and Hashing](B07-encoding-and-hashing/) | Base64, SHA-256 |
| B08 | [File Forensics](B08-file-forensics/) | file, strings, stat, metadata |
| B09 | [Identity Log Triage](B09-identity-log-triage/) | login success/failure, sessions |
| B10 | [Security Monitoring](B10-security-monitoring/) | events, alerts, correlation |
| B11 | [Incident Response Mini Case](B11-incident-response-mini-case/) | triage, containment, evidence |
| B12 | [Beginner Skills Challenge](B12-beginner-skills-challenge/) | multi-skill review |

## Difficulty Model

These labs are intentionally more guided than the original numbered Extra Practice catalog.

~~~text
Beginner Event
   ↓
Matching B-lab
   ↓
Repeat until comfortable
   ↓
Beginner CTF / readiness interview
   ↓
Intermediate
~~~

## Flags

Filled flag values are supplied at runtime from the private instructor repository.

Students submit discovered values to the CyberLabs dashboard.
