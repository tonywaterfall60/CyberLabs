# B06 — Packet Reading

## Goal

Practice reading basic network evidence before working with larger PCAP files.

## Setup

~~~bash
chmod +x setup.sh
./setup.sh
cd ~/cyberclub/extra-beginner-b06
~~~

## Tasks

Use `packet-summary.txt` to answer:

1. Which host made the DNS query?
2. What name was requested?
3. Which TCP port was contacted?
4. Which frames represent the beginning of a TCP handshake?
5. What HTTP method was used?
6. What response status was returned?
7. Recover the flag.

## Deliverable

Submit the flag and a five-step timeline from DNS lookup through HTTP response.

## Skill Connection

After this feels comfortable, repeat the same reasoning in Wireshark using Beginner 05.
