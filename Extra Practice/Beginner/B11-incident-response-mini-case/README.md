# B11 — Incident Response Mini Case

## Goal

Practice the basic incident-response flow without needing a full SIEM or forensic image.

## Setup

~~~bash
chmod +x setup.sh
./setup.sh
cd ~/cyberclub/extra-beginner-b11
~~~

## Tasks

Read `case.txt` and organize your response into:

1. **Triage** — what happened?
2. **Containment** — what would you isolate or restrict first?
3. **Evidence preservation** — what should be saved before making changes?
4. **Eradication** — what would need to be removed or corrected after confirmation?
5. **Recovery** — what checks should happen before returning the system to normal use?
6. **Lessons learned** — what logging or control would help next time?

Recover the flag after reviewing the full case.

## Deliverable

Submit the flag and a short response plan using the six headings above.
