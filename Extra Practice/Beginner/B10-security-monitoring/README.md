# B10 — Security Monitoring

## Goal

Practice turning individual events into a simple security timeline.

## Setup

~~~bash
chmod +x setup.sh
./setup.sh
cd ~/cyberclub/extra-beginner-b10
~~~

## Tasks

1. Identify the first alert.
2. Identify the process relationship.
3. Identify the DNS event.
4. Identify the later network event.
5. Build a four-event timeline.
6. Explain which events are observations and which conclusions would still be guesses.
7. Recover the flag.

## Deliverable

Submit the flag, timeline, and one sentence describing what additional evidence you would want.
