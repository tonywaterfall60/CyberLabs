# B09 — Identity Log Triage

## Goal

Practice reading simple authentication logs and following a user/session timeline.

## Setup

~~~bash
chmod +x setup.sh
./setup.sh
cd ~/cyberclub/extra-beginner-b09
~~~

## Tasks

1. Count failed logins.
2. Identify the user with failed attempts.
3. Identify the source IP.
4. Find the later successful session ID.
5. Build a short timeline for Alex.
6. Recover the flag associated with that session.

Useful commands:

~~~bash
grep
sort
cat
~~~

## Deliverable

Submit the flag and a short timeline.

Also explain the difference between authentication and authorization.
