# CyberLabs Curriculum Index

# Beginner Track

**Goal:** guided cybersecurity foundations and first technical labs.

[Beginner Track Overview](beginner/README.md)

| # | Event | Focus |
|---:|---|---|
| 01 | [Intro to Cybersecurity](beginner/01-intro-to-cybersecurity/) | security foundations, risk, CIA, basic analysis |
| 02 | [Linux Basics](beginner/02-linux-basics/) | Linux navigation, files, permissions, evidence |
| 03 | [Networking Fundamentals](beginner/03-networking-fundamentals/) | IP, DNS, TCP/UDP, ports, troubleshooting |
| 04 | [Command Line Workshop](beginner/04-command-line-workshop/) | pipes, redirection, grep, sorting, log filtering |
| 05 | [Intro to Wireshark](beginner/05-intro-to-wireshark/) | packets, streams, basic PCAP analysis |
| 06 | [Intro to Nmap](beginner/06-intro-to-nmap/) | scoped port and service discovery |
| 07 | [Web Security Basics](beginner/07-web-security-basics/) | HTTP, routes, sessions, access-control concepts |
| 08 | [Intro to Cryptography](beginner/08-intro-to-cryptography/) | encoding, hashing, integrity, encryption concepts |
| 09 | [Intro to Digital Forensics](beginner/09-intro-to-digital-forensics/) | evidence preservation, hashes, metadata, strings |
| 10 | [Beginner CTF](beginner/10-beginner-ctf/) | multi-topic skill integration |
| 11 | [Capstone Interview Prep](beginner/11-capstone-interview-prep/) | Intermediate-readiness review |

| # | Event | Focus |
