# Advanced 26 — Incident Command / Major Incident Response

## Event Snapshot

| Item | Details |
|---|---|
| Track | Advanced |
| Difficulty | Advanced |
| Estimated time | 120–150 minutes |
| Environment | Static/synthetic professional security evidence |
| Prerequisites | DevSecOps / Supply Chain II |

## Why This Event Exists

Major incidents require coordination, decision logging, evidence preservation, communication, and role clarity in addition to technical analysis.

## Learning Objectives

- assign incident-command roles
- separate tactical analysis from executive decisions
- maintain a decision log
- prioritize containment under uncertainty
- write technical and executive status updates

## Concepts

Emphasize evidence quality, decision-making, business/technical tradeoffs, limitations, and defensible communication.

## Guided Lab

The event lead should model one worked example, then require members to complete the remaining assessment independently.

## Challenge

[challenge/README.md](challenge/README.md)

## Expected Outcomes

Members should produce work that could be handed to another analyst, engineer, or stakeholder without relying on hidden context.

## Cleanup

No cleanup is required for these static/synthetic exercises.
