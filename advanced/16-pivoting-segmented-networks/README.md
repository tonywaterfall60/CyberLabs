## Why This Event Exists

Network segmentation changes what systems are reachable from where. Advanced members should reason about pivots, jump hosts, tunnels, and what a route does and does not prove.

## Learning Objectives

- interpret multi-subnet routing,
- reason about jump hosts and SOCKS tunnels,
- distinguish reachability from compromise,
- identify segmentation failures,
- propose pivot detection telemetry.
