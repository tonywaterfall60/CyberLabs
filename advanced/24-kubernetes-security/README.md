## Why This Event Exists

Kubernetes combines identity, workload configuration, networking, secrets, and host-boundary decisions. Security review requires understanding how those layers interact.

## Learning Objectives

- review pod/workload security context
- analyze service accounts and RBAC
- identify exposed secrets and privileged settings
- evaluate network-policy coverage
- recommend layered Kubernetes hardening

## Concepts

Focus on trust boundaries, evidence quality, competing explanations, prevention, detection, and residual risk.

## Guided Lab

The event lead should model one evidence-to-conclusion chain, then require members to independently validate the remaining relationships.
