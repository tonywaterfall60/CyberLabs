## Why This Event Exists

SIEM engineering is about reliable data pipelines, schemas, parsing, normalization, correlation, retention, and detection quality—not just dashboards.

## Learning Objectives

- normalize multiple log formats,
- choose stable correlation fields,
- identify schema drift,
- design useful retention/enrichment,
- explain how parser failures affect detections.
