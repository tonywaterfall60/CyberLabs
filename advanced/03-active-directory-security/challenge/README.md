# Challenge — Fictional AD Attack-Path Analysis

Everything in this folder is fictional exported directory data.

## Files

- `users.csv`
- `groups.csv`
- `memberships.csv`
- `spns.csv`
- `delegation.csv`

## Tasks

1. Identify privileged groups.
2. Identify all users who can reach a privileged group through nested membership.
3. Identify service accounts with SPNs.
4. Identify any risky delegation relationship.
5. Build at least one plausible attack path.
6. Label each step as:
   - observed
   - inferred
   - requires validation
7. Recommend three identity-hardening actions.

## Rule

Do not use this dataset to pivot toward real university identities or infrastructure.

No filled-in flag is committed here. If the instructor wants a flag-based version, they can inject one in the private event overlay.
