## Why This Event Exists

Alerts should come from clearly defined behavior and tested logic. This event introduces fields, selections, false positives, thresholds, and simple positive/negative test cases.

## Learning Objectives

- identify required telemetry,
- write simple detection logic,
- distinguish positive and negative tests,
- discuss false positives,
- explain why detections require maintenance.
