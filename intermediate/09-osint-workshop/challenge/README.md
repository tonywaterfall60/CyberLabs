# Challenge — Fictional OSINT Investigation

A fictional organization called **Northstar Robotics Club** has several public artifacts in this folder.

## Tasks

1. Identify all usernames connected to the organization.
2. Correlate usernames across the provided artifacts.
3. Identify the likely event date.
4. Identify the domain used by the organization.
5. Build a short timeline.
6. Identify one conclusion that is strongly supported.
7. Identify one conclusion that would be irresponsible to make from this data alone.

## Files

- `website.txt`
- `social-posts.txt`
- `conference-bio.txt`
- `whois-summary.txt`

## Rule

Everything is fictional. Do not pivot to real people, accounts, or domains.
