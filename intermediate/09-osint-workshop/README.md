# Intermediate 09 — OSINT Workshop

**Difficulty:** Intermediate  
**Estimated time:** 90 minutes  
**Prerequisites:** Intermediate 08  
**Environment:** Local fictional dataset; optional web research only when explicitly authorized

## Why This Event Exists

OSINT is about disciplined collection and verification of publicly available information. This event emphasizes methodology, corroboration, source quality, and privacy rather than intrusive collection.

## Learning Objectives

Members should be able to:

- define an OSINT question before collecting data
- distinguish primary and secondary sources
- assess source reliability
- correlate usernames, timestamps, domains, and public artifacts
- document provenance
- avoid overclaiming based on weak evidence

## Workflow

```text
Define a question
      ↓
Identify allowed sources
      ↓
Collect only relevant facts
      ↓
Record provenance
      ↓
Corroborate across artifacts
      ↓
Build entity/timeline views
      ↓
State confidence and uncertainty
```

Intermediate OSINT is not "find as much as possible."

It is disciplined collection tied to a defined question.

## Challenge

Use only the fictional data in `challenge/`.

The expanded dataset includes:

```text
website.txt
social-posts.txt
conference-bio.txt
whois-summary.txt
event-flyer.txt
repository-profile.txt
```

Students now build a provenance table, entity map, timeline, corroboration assessment, and explicit unsupported-conclusion example.

## Deliverable

Create:

- an entity map
- a timeline
- three supported conclusions
- one unresolved uncertainty
- a confidence rating for each conclusion
