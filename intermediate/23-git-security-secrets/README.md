## Why This Event Exists

Deleting a secret from the latest file does not necessarily remove it from repository history. Members learn commits, diffs, .gitignore, secret rotation, and why repository hygiene matters.

## Learning Objectives

- read a simplified Git history,
- identify when a secret entered history,
- distinguish deletion from revocation,
- explain .gitignore limitations,
- recommend safe remediation.
