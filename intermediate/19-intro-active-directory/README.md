## Why This Event Exists

Active Directory appears throughout enterprise security. Members need to understand domains, users, groups, computers, service accounts, group nesting, and why identity relationships matter before advanced attack-path analysis.

## Learning Objectives

- identify AD object types,
- trace group membership,
- distinguish human and service identities,
- explain local admin vs domain admin conceptually,
- recognize why nested groups affect privilege.
