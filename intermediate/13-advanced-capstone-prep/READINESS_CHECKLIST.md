# Intermediate → Advanced Readiness Checklist

Use this before the mock interview.

## I can do these without exact commands being handed to me

- [ ] define authorized scope
- [ ] choose an enumeration method
- [ ] manually validate an automated result
- [ ] map a web application's routes, methods, parameters, and trust boundaries
- [ ] explain authentication vs. authorization with a concrete example
- [ ] compare online and offline password risks
- [ ] identify a privilege-boundary relationship from static evidence
- [ ] reconstruct a packet or log timeline
- [ ] correlate two or more evidence sources
- [ ] write a small Python parser for a structured log
- [ ] explain static vs. dynamic reverse engineering
- [ ] distinguish observation, inference, and unknown
- [ ] recommend root-cause remediation
- [ ] propose useful detection/monitoring
- [ ] explain what evidence would change my conclusion

## I should review before Advanced if these are still difficult

- [ ] I treat scanner output as proof
- [ ] I cannot explain why I chose a tool
- [ ] I jump to exploitation before mapping/validation
- [ ] I make conclusions without citing evidence
- [ ] I do not know when to say `unknown`
- [ ] I forget to confirm scope
- [ ] I can identify a weakness but cannot explain impact/remediation

## Final Prompt

Explain one investigation from start to finish using:

~~~text
Scope
Question
Evidence
Tool
Validation
Conclusion
Uncertainty
Remediation
Detection
~~~
