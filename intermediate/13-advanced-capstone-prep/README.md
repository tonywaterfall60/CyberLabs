# Intermediate 13 — Advanced Capstone Prep

**Difficulty:** Intermediate capstone preparation  
**Estimated review time:** 60 minutes  
**Prerequisites:** Intermediate 01–12

## Purpose

Prepare for the Intermediate → Advanced mock interview.

## Be Ready to Explain

### Enumeration
- scope definition
- discovery vs. fingerprinting vs. validation
- service prioritization
- web attack-surface mapping

### Web Security
- broken access control
- injection risk
- security misconfiguration
- authentication failures
- logging/monitoring gaps

### Password Security
- salts
- slow password hashing
- online vs. offline attacks
- MFA and rate limiting

### Privilege Escalation Foundations
- writable privileged scripts
- sudo/service/task misconfiguration
- plaintext credentials
- privilege/token concepts
- remediation

### Analysis
- packet filtering and TCP streams
- log correlation and timelines
- confidence and evidence quality

### Automation
- parsing logs with Python
- using dictionaries/counters
- turning manual analysis into repeatable scripts

### Reverse Engineering
- file metadata
- strings/imports
- static vs. dynamic analysis
- program-flow reasoning

## Practice Questions

1. How do you prioritize services after enumeration?
2. What evidence separates an observation from a vulnerability claim?
3. Why are salts useful?
4. Why are password-hashing algorithms intentionally slow?
5. What makes a privileged writable script dangerous?
6. How would you correlate a suspicious login with application activity?
7. When should you automate an analysis task?
8. What can `strings` tell you, and what can it not prove?
9. What should you include in remediation guidance?
10. What should you verify before testing any target?
