## Why This Event Exists

This event advances beyond wireless vocabulary into management-frame analysis, client behavior, security modes, and assessment limitations without requiring live RF interaction.

## Learning Objectives

- correlate beacon/probe/auth/association events,
- compare open vs protected APs,
- identify directed probes,
- build a client/AP timeline,
- explain what capture evidence cannot prove.
