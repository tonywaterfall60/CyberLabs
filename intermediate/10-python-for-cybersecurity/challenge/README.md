# Challenge — Build a Log Parser

Run:

```bash
python3 parser.py auth.log
```

## Requirements

Complete the TODO sections so the script prints:

1. failed logins by user
2. failed logins by source IP
3. successful login count
4. most frequent failed-login source

## Stretch Goals

- sort output by count
- add a `--user` filter
- output JSON

Do not add network activity; this challenge is local file analysis only.
