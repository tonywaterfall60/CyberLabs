## Why This Event Exists

Containers are common in CyberLabs and production systems. Members need to understand images, containers, ports, volumes, users, environment variables, and why host boundaries matter.

## Learning Objectives

- distinguish image vs container,
- interpret Dockerfile instructions,
- understand port publishing and volumes,
- identify root/non-root execution,
- recognize plaintext secret risks.
