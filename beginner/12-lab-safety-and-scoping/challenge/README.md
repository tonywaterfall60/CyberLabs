# Challenge — Read the Scope Before the Tool

## Challenge Snapshot

| Item | Details |
|---|---|
| Difficulty | Beginner |
| Estimated time | 30–45 minutes |
| Environment | Written analysis |
| Authorized scope | Fictional scope cards in this challenge only |
| Goal | Translate written authorization into precise allowed/prohibited actions |

## Scenario

You are preparing for four different club labs. Each has different authorization.

## Authorized Scope

This challenge is analysis-only.

## Setup

Read `scope-cards.md`.

## Investigation / Tasks

For each card identify:

~~~text
Allowed targets
Allowed ports/files
Allowed actions
Prohibited actions
Stop condition
Evidence to record
~~~

Then answer whether each proposed command/action is authorized.

## Deliverable

Submit one scope table per scenario and explain one ambiguous case where you would stop and ask an event lead.

## Cleanup

No cleanup is required.
