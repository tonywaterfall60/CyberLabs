## Why This Event Exists

Members need a repeatable way to decide what is authorized before using security tools. This event turns scope, rules of engagement, and evidence handling into practical habits.

## Learning Objectives

Members should be able to:

- identify authorized and unauthorized targets,
- interpret host/port/subnet scope,
- explain stop conditions,
- preserve evidence without over-collecting,
- document assumptions before testing.

## Concepts


## Guided Lab

Practice reading several fictional scope statements and translating them into exact allowed hosts, ports, files, actions, and prohibited actions.
