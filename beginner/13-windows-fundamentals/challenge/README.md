# Challenge — Windows Endpoint Orientation

## Challenge Snapshot

| Item | Details |
|---|---|
| Difficulty | Beginner |
| Estimated time | 35–50 minutes |
| Environment | Fictional Windows command outputs |
| Authorized scope | Files in this challenge directory |
| Goal | Build a basic endpoint inventory |

## Scenario

A fictional Windows workstation was collected for routine security review.

## Authorized Scope

Use only `endpoint.txt`.

## Setup

No live Windows system is required.

## Investigation / Tasks

Identify:

- hostname and current user,
- IP address and gateway,
- listening services,
- one running security process,
- one service that starts automatically,
- one useful PowerShell command for each category.

## Deliverable

Create:

~~~text
Host:
User:
Groups:
IP:
Gateway:
Listening ports:
Interesting process:
Interesting service:
Commands you would run next:
~~~

No cleanup is required.
