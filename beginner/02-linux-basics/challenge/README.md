# Challenge — Linux Log Hunt

Run:

```bash
./setup.sh
```

The setup creates a training directory in:

```text
~/cyberclub/linux-challenge
```

## Rules

Use terminal commands only. Avoid opening the entire directory in a GUI file browser.

## Tasks

1. Find the file containing the string `FAILED_LOGIN`.
2. Identify how many failed-login entries exist.
3. Find the hidden file in the challenge directory.
4. Display the contents of that hidden file.
5. Identify your current username.
6. Identify one IP address assigned to your machine.
7. Find the file owned by you that contains the word `FLAG`.

## Deliverable

Record the command used for each task.

## Cleanup

```bash
./reset.sh
```
