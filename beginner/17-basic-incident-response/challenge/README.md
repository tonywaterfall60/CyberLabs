## Scenario

A fictional user reports a suspicious document and unusual account activity.

## Authorized Scope

Use only the provided case evidence.

## Setup

No setup is required.

## Investigation / Tasks

1. Build the timeline.
2. Identify affected user and endpoint.
3. Separate observed facts from assumptions.
4. Choose immediate containment.
5. List evidence to preserve before remediation.
6. Propose recovery/follow-up actions.
