# Challenge — Wireless Inventory Review

## Challenge Snapshot

| Item | Details |
|---|---|
| Difficulty | Beginner |
| Estimated time | 30–40 minutes |
| Environment | Static synthetic wireless observations |
| Authorized scope | wireless-observations.csv |
| Goal | Build a simple wireless security inventory |

## Scenario

You receive an offline summary from a fictional wireless capture.

## Authorized Scope

No live Wi-Fi interaction is authorized.

## Setup

Open `wireless-observations.csv`.

## Investigation / Tasks

Identify each SSID, BSSID, channel, security mode, and client association.

Answer:

- which network is open,
- which two are protected,
- why an SSID alone does not prove ownership,
- what additional evidence a real wireless assessment would need.

## Deliverable

Submit a three-row wireless inventory and four short conclusions.

## Cleanup

No cleanup is required.
