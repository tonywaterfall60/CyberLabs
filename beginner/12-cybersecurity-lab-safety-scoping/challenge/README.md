# Challenge — Cybersecurity Lab Safety & Scoping

## Challenge Snapshot

| Item | Details |

| Difficulty | Beginner |

## Scenario

You are given a fictional club assessment request containing approved systems, excluded systems, allowed techniques, and timing restrictions. Your job is to turn it into an operational scope before testing begins.

## Authorized Scope

Use only the fictional engagement brief in challenge/engagement-brief.txt. Do not perform any real scanning.

## Setup

No external target is required. Work from the files in this challenge directory.

## Investigation / Tasks

### Phase 1 — Extract in-scope hosts, ports, dates, and techniques.

Document the evidence or reasoning used for this step.

### Phase 2 — List every explicit exclusion.

Document the evidence or reasoning used for this step.

### Phase 3 — Write three stop conditions.

Document the evidence or reasoning used for this step.

### Phase 4 — Classify five proposed actions as allowed, disallowed, or requires clarification.

Document the evidence or reasoning used for this step.

### Phase 5 — Produce a one-paragraph scope statement.

Document the evidence or reasoning used for this step.

## Deliverable

Scope statement, allowed/disallowed action table, stop conditions, and one escalation question.

## Cleanup

No cleanup is required for this static-data challenge.
