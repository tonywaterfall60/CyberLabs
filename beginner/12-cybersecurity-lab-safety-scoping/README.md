## Why This Event Exists

This event teaches the operating rules that make hands-on security work safe, legal, reproducible, and professionally defensible.

## Learning Objectives

- identify an authorized target, port range, file set, or subnet
- distinguish in-scope from out-of-scope actions
- write a short rules-of-engagement statement
- recognize when to stop and request additional authorization
- document commands and evidence without collecting unnecessary data

## Concepts

- **Authorization:** Permission must exist before testing begins.
- **Scope:** Defines exactly what systems, files, ports, identities, and techniques are allowed.
- **Rules of engagement:** Operational limits such as no denial of service or credential guessing.
- **Stop conditions:** Events that require the analyst to stop and escalate.

## Guided Lab

Use the local challenge in `challenge/`. Start by identifying scope, then collect evidence, explain what it means, identify uncertainty, and recommend a safe next step.
