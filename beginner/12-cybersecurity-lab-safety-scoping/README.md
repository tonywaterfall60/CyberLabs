## Why This Event Exists

Build the habit of defining authorization, scope, stop conditions, and evidence boundaries before touching security tools.

## Learning Objectives

By the end of this event, members should be able to:

- identify authorized and unauthorized targets from a written engagement
- write a concise scope statement
- recognize when a requested action exceeds authorization
- document stop conditions and escalation steps

## Concepts

The event lead should introduce the core vocabulary needed for the challenge and connect it to earlier Beginner material.

## Guided Lab

Work through the challenge evidence together once, focusing on **what question is being asked before choosing a command or conclusion**.
