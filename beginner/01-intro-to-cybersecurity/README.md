# Beginner 01 — Intro to Cybersecurity

**Time:** 60–75 minutes  
**Environment:** No VM required

## Objectives
Members should be able to explain:
- confidentiality, integrity, and availability
- threat vs. vulnerability vs. risk
- authentication vs. authorization
- attack surface
- why authorization matters in security testing

## Activity
For each scenario identify:
1. The asset
2. The threat
3. The vulnerability
4. Possible impact
5. One mitigation

### Scenario A
A student reuses the same password across several services.

### Scenario B
A web application exposes administrative functions without checking user roles.

### Scenario C
An organization has backups but has never tested restoring them.

## Mini Challenge
For each scenario, identify which CIA property is most directly affected.

## Reflection
What makes cybersecurity different from simply "hacking"?
