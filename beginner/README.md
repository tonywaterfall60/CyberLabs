# Beginner Track

The Beginner track builds core cybersecurity foundations before members move into more technical intermediate labs.

## Recommended Order

1. [Intro to Cybersecurity](01-intro-to-cybersecurity/)
2. [Linux Basics](02-linux-basics/)
3. [Networking Fundamentals](03-networking-fundamentals/)
4. [Command Line Workshop](04-command-line-workshop/)
5. [Intro to Wireshark](05-intro-to-wireshark/)
6. [Intro to Nmap](06-intro-to-nmap/)
7. [Web Security Basics](07-web-security-basics/)
8. [Intro to Cryptography](08-intro-to-cryptography/)
9. [Intro to Digital Forensics](09-intro-to-digital-forensics/)
10. [Beginner CTF](10-beginner-ctf/)
11. [Intermediate Advancement Capstone Prep](11-capstone-interview-prep/)

## What Members Should Know by the End

A member completing the Beginner track should be able to:

- explain basic cybersecurity concepts and scope
- navigate Linux and use common command-line tools
- explain IP addresses, DNS, TCP/UDP, and ports
- inspect simple traffic in Wireshark
- interpret basic Nmap results on an authorized target
- explain HTTP, authentication, authorization, and input validation
- distinguish encoding, hashing, and encryption
- calculate and interpret file hashes
- document basic technical findings
- explain why authorization is required before security testing

## Advancement

After completing the Beginner CTF, members may take the Beginner → Intermediate mock interview.

Passing the capstone unlocks the Intermediate track beginning with:

```text
intermediate/01-network-enumeration
```

## Event Format

A typical Beginner event should target 60–90 minutes:

| Time | Activity |
|---|---|
| 0–10 min | Review / introduction |
| 10–30 min | Concepts and demonstration |
| 30–65 min | Guided hands-on lab |
| 65–80 min | Challenge |
| 80–90 min | Review and questions |

## Instructor Notes

Keep the pace accessible. Members should understand why a tool or command is being used before being expected to memorize syntax.
