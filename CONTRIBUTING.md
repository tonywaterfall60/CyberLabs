# Contributing

Club members and E-board members are encouraged to contribute labs, fixes, documentation, and challenge ideas.

## New Lab Requirements
Every lab should contain:
- `README.md`
- learning objectives
- difficulty level
- estimated completion time
- prerequisites
- required software
- setup instructions
- student tasks
- cleanup/reset instructions
- reflection/review questions

Use `templates/LAB_TEMPLATE.md` as the starting point.

## Pull Request Checklist
- Test the lab from a clean environment.
- Remove real credentials, API keys, tokens, and personal data.
- Confirm offensive activity is limited to an authorized local lab.
- Verify commands and screenshots.
- Confirm cleanup instructions work.
- Keep instructor solutions out of the student-facing directory.
