# Workstation Setup

## Goal
Prepare a member laptop for club labs using free software.

## Recommended Software
- Git
- VirtualBox or VMware Workstation
- Docker Desktop or Docker Engine
- Wireshark
- Modern web browser
- Optional: VS Code

## Suggested Hardware

### Light labs
- 8 GB RAM
- 20 GB free storage

### VM-heavy labs
- 16 GB RAM recommended
- 60+ GB free storage

## Verification
```bash
git --version
docker --version
```

## Clone the Repository
```bash
git clone https://github.com/tonywaterfall60/CyberLabs.git
cd CyberLabs
```

## Safety
Do not bridge intentionally vulnerable lab machines directly onto campus or public networks. Use host-only, internal, or NAT networking as specified by each lab.
